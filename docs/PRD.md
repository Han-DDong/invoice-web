# Invoice Web MVP PRD

## 🎯 핵심 정보

**목적**: 노션에 입력한 견적서를 클라이언트가 링크 하나로 웹에서 확인하고 PDF로 내려받게 한다.
**사용자**: 노션으로 견적서를 관리하는 프리랜서/1인 개발자(작성자)와, 견적서를 전달받는 클라이언트.

## 🚶 사용자 여정

```
[작성자] 노션 견적서 DB에 견적서 작성 → 상태를 "발행"으로 변경 → 공유 링크 전달

1. 견적서 상세 페이지 (공유 링크로 진입)
   ↓ 링크의 토큰 검증

   [토큰 유효 + 발행 상태] → 견적서 내용 표시
   [토큰 무효 / 미발행 / 만료] → 접근 불가 페이지
   ↓

2. 견적서 확인 (항목, 금액, 유효기간)
   ↓ "PDF 다운로드" 클릭

3. PDF 파일 저장 → 완료

* 홈 페이지는 서비스 소개 전용이며 견적서 목록을 노출하지 않음
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 노션 견적서 조회 | 노션 DB에서 견적서와 항목을 읽어 화면용 데이터로 변환 | 노션을 CMS로 쓰는 구조의 핵심 | 견적서 상세 페이지 |
| **F002** | 견적서 웹 보기 | 발행처, 수신처, 항목 표, 합계/부가세, 유효기간, 비고를 반응형으로 표시 | 클라이언트가 내용을 확인하는 핵심 가치 | 견적서 상세 페이지 |
| **F003** | PDF 다운로드 | 현재 견적서를 PDF 파일로 생성해 다운로드 | 클라이언트 보관/전달 니즈 | 견적서 상세 페이지 |
| **F004** | 공유 링크 접근 제어 | 추측 불가능한 토큰 URL과 "발행" 상태인 견적서만 열람 허용 | 인증 없이 안전하게 공유하기 위한 최소 장치 | 견적서 상세 페이지, 접근 불가 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F010** | 오류/빈 상태 안내 | 노션 조회 실패, 잘못된 링크, 미발행/만료 견적서 안내 | 실패 시 사용자 혼란 방지 | 접근 불가 페이지 |
| **F011** | 테마 전환 | 라이트/다크/시스템 테마 (스타터 킷 기존 기능 재사용) | 기존 레이아웃에 포함되어 추가 비용 없음 | 홈 페이지, 견적서 상세 페이지, 접근 불가 페이지 |
| **F012** | 서비스 소개 | 서비스 설명과 사용 방법 안내 | 링크 없이 접속한 방문자 안내 | 홈 페이지 |

### 3. MVP 이후 기능 (제외)

- 회원가입/로그인, 작성자 대시보드, 견적서 목록 관리
- 웹에서 견적서 작성/수정 (작성은 노션에서만)
- 클라이언트 승인/서명/코멘트, 이메일 발송, 알림
- 다국어, 다중 통화, 견적서 템플릿 커스터마이징
- 열람 이력 통계, 비밀번호 보호 링크

│   └── 기능: F001, F002, F003, F004, F011

    └── 기능: F004, F010, F011

## 🗄️ 데이터 모델

데이터 소스는 노션 데이터베이스이며, 웹 서비스는 별도 DB를 두지 않는다.

### 견적서 DB (노션)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| 견적번호 | 사람이 읽는 번호 (예: Q-2026-001) | Title |
| 공유토큰 | 추측 불가능한 랜덤 문자열 (URL에 사용) | Text |
| 상태 | 초안 / 발행 / 만료 | Select |
| 수신처 | 클라이언트 회사/담당자명 | Text |
| 발행일, 유효기간 | 견적 발행일과 유효 종료일 | Date |
| 부가세율, 비고 | 세율(기본 10%)과 안내 문구 | Number, Text |

### 견적 항목 DB (노션)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| 품목명 | 작업/제품 이름 | Title |
| 견적서 | 소속 견적서 | Relation → 견적서 DB |
| 수량 | 수량 | Number |
| 단가 | 개당 금액 | Number |
| 금액 | 수량 x 단가 (노션 수식, 합계는 웹에서 재계산) | Formula |

## 📄 PDF 생성 방식 비교

| 방식 | 장점 | 단점 | 판단 |
|------|------|------|------|
| `@react-pdf/renderer` | 서버리스 친화적, 가벼움, 레이아웃 제어 쉬움 | 한글 폰트 직접 등록 필요, 웹 화면과 별도 컴포넌트 | **권장** |
| Puppeteer 계열(headless Chrome) | 웹 화면과 동일한 결과 | Vercel에서 용량/콜드스타트 부담 | 보류 |
| 브라우저 인쇄(`window.print`) | 구현 최소 | 파일 직접 다운로드 불가, 결과 편차 | 보조 수단 |

권장안: `@react-pdf/renderer`로 서버에서 PDF를 생성하고, 한글 폰트(Pretendard 등)를 번들에 포함한다.
